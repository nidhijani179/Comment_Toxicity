# Comment Toxicity Detection Model

This project focuses on building a **machine learning model** to detect toxic comments in text data. It was developed as part of the **Jigsaw Toxic Comment Classification Challenge** and reached the **Finalist stage in the Code Unnati Marathon**, showcasing its real-world impact and technical excellence.

---

## 📂 Project Structure
comment-toxicity-model-main/
│
├── Toxicity.ipynb # Jupyter Notebook with the model pipeline
├── jigsaw-toxic-comment-classification-challenge/ # Dataset or related challenge files
└── README.md # Project documentation


---

## ✨ Features
- Detects multiple types of toxic comments including:
  - Toxic  
  - Severe Toxic  
  - Obscene  
  - Threat  
  - Insult  
  - Identity Hate  
- End-to-end workflow: Data preprocessing → Model training → Evaluation  
- Built with **Python** and popular ML libraries like **scikit-learn** and **TensorFlow/Keras**  
- Achieved **finalist position** in Code Unnati Marathon  

---

## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/your-username/comment-toxicity-model.git
cd comment-toxicity-model-main

Install Dependencies

Install the required Python packages:

pip install -r requirements.txt


(If requirements.txt is missing, install manually: pip install pandas numpy scikit-learn tensorflow)

▶️ How to Run

Open the Jupyter Notebook:

jupyter notebook Toxicity.ipynb


Follow the cells in order to preprocess the data, train the model, and evaluate its performance.

🛠 Technologies Used

Python 3.7+

Pandas & NumPy for data handling

Scikit-learn for preprocessing & baseline models

TensorFlow / Keras for deep learning models

Matplotlib & Seaborn for visualization

📊 Model Output

Predicts multiple labels for each comment

Provides probabilities for each toxicity class

Can be extended for real-time toxicity detection APIs
